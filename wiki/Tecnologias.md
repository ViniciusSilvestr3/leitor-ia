# Tecnologias utilizadas

| Tecnologia | Uso no projeto |
|---|---|
| JavaScript | Lógica do frontend e do backend |
| HTML | Estrutura da interface |
| CSS | Estilos e temas da aplicação |
| Node.js | Runtime do servidor |
| Express 5 | Servidor HTTP e API |
| SQLite3 | Persistência local de usuários e flashcards |
| Google GenAI | Integração com o Google Gemini |
| Gemini | Tradução, explicação contextual, análise literária e perguntas |
| JSON Web Token | Autenticação das requisições protegidas |
| bcrypt | Hash das senhas |
| epub.js | Leitura de arquivos EPUB |
| JSZip | Suporte utilizado pelo epub.js |
| PDF.js | Renderização e seleção de texto em PDF |
| npm | Instalação e gerenciamento das dependências |

As bibliotecas de leitura são carregadas por CDN no frontend. Por isso, a aplicação precisa de acesso à internet para carregá-las.
