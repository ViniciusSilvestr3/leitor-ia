# Leitor Inteligente

## Apresentação da P1

O **Leitor Inteligente** é uma aplicação web para leitura de livros digitais e estudo de vocabulário com apoio de inteligência artificial. A aplicação permite abrir arquivos EPUB e PDF no navegador, selecionar palavras ou trechos e receber tradução, explicação contextual e análise literária geradas pelo Google Gemini.

O processamento dos livros ocorre localmente no navegador. O arquivo físico não é enviado ao backend; o servidor recebe somente os dados textuais necessários para realizar a análise.
